Each organisation is a completely separate set of accounts, transactions, categories, rules and budgets, stored in its own database file. Use them for different people, or to keep groups of bank, card and loan accounts apart. Switch with the menu at the top right. The list of organisations is kept in its own small file, data/orgs.db, which holds only names and file locations.
